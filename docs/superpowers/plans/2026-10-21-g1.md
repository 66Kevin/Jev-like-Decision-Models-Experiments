- Training uses 960 cases / 4,800 decisions; dev 120/600; official test 400/2,000. Calibration stays unused. No soft gold CE/Brier, label smoothing, temperature fitting, candidate permutations or task-specific prompt tuning.
- Rank 16, alpha 32, dropout 0, bias none. - PEFT adapters FP32 and base weights BF16; only adapter A/B parameters trainable. Native LM Head output at last token, FP32 cross entropy normalized over each decision's valid candidate letters. Labels use the same stable identity argmax as B0. Weight tying and frozen original parameters must remain intact.
- AdamW LR 2e-4, weight decay .01, max grad norm 1, 3 epochs, effective batch 32 questions (microbatch 8 × accumulation 4 unless memory-only preflight requires an explicitly recorded smaller microbatch with the same effective size), cosine schedule with 5% warmup, seeds 42/43/44.

Write a locked selection manifest for all seeds before any G1 test inference. No test-driven hyperparameter adjustments.
- Pretokenize training prompts with the unchanged B0 formatter; batch questions independently with left padding and attention-mask positions. Evaluation remains five questions per case, batch one case, unchanged candidate/readout/timing protocol. Keep adapters unmerged for the primary comparison.
- Training may use project-local FLA kernels if native backward performance is prohibitive, but only after train-only forward/gradient validation and with explicit runtime provenance. Model construction and all dev/test evaluation use the original native PyTorch DeltaNet/normalization/conv path to preserve B0 comparability. No global Conda mutation or downloads of model weights.
