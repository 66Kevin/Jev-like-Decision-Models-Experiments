# B0 Baseline Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for implementation and independent review. The user has authorized creation of the agreed directories and completion of B0; do not stop for another implementation approval.

**Goal:** Evaluate the unchanged local Qwen3.5-0.8B on the official typed-decisions dev/test cases and save reproducible B0 artifacts.

**Architecture:** Four numbered experiment directories call shared data, model and evaluation modules. B0 reads single-token A/B/C candidate logits from one independent causal prompt per question, renormalizes over candidates and never generates or trains. A case comprises all five questions; latency includes tokenization and synchronized inference, excludes model load and file writing, and uses one case per batch.

**Tech Stack:** Existing Conda torch29-cu130 (Python 3.13, torch 2.9.0, transformers 5.14.1, datasets 5.0.0, numpy 2.2.6, PyYAML 6.0.2); standard-library unittest for deterministic mathematical and leakage tests.

**Workspace:** The mounted .git is not a functional Git repository, so work directly in the user workspace without initializing Git or making commits. The host GPU is available through approved escalated commands; use idle physical GPU 1 without modifying any running workloads.

**Plan review:** Independently approved before implementation. Record hashes of weights, tokenizer, chat template and model config; retain explicit Score level mappings and validate one real expected-score calculation.
